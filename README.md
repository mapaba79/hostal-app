# 🏨 Sistema de Gestión para Hostal

Este es un sistema simple y fácil de usar para gestionar el **check-in, check-out y reservas** de habitaciones privadas, compartidas y para voluntarios en un hostal. Diseñado para funcionar **localmente en un solo computador**, sin necesidad de internet ni servidores externos.

---

## 🚀 Funcionalidades

- 📋 Gestión de habitaciones privadas (6 en total)
- 🛏️ Gestión individual de camas en:
  - Habitación compartida (18 camas)
  - Habitación de voluntarios (9 camas)
- ✅ Check-in y check-out con registro de fechas
- 🧑‍💼 Búsqueda de huéspedes por nombre
- 📖 Historial de reservas
- 🖨️ Exportación del historial en **PDF**
- 🔐 Sistema con **contraseña de acceso**
- 🛠️ Posibilidad de cambiar la contraseña
- 📎 Atajo en el escritorio (como si fuera una app)

---

## 📦 ¿Cómo usar?

1. **Descarga o copia** todos los archivos del sistema:
   - `index.html`
   - `app.js`
   - `style.css`
2. Abre el archivo `index.html` en cualquier navegador moderno (Chrome recomendado).
3. Ingresa la contraseña para acceder. (Contraseña por defecto: `hostel123`)
4. ¡Listo! Ya puedes comenzar a usar el sistema.

---

## 🔒 Cambiar contraseña

Puedes cambiar la contraseña desde el menú del sistema con el botón **"Alterar contraseña"**.

---

## 📎 Crear un atajo en el escritorio

Puedes crear un atajo para abrir el sistema como una app:

### En Windows:
- Abre `index.html` con Google Chrome.
- Clic en los 3 puntos (arriba a la derecha) > **Más herramientas** > **Crear acceso directo**
- Marca **"Abrir como ventana"** y crea el acceso directo.

### En Linux:
- Igual que en Windows, usando Google Chrome o Chromium.
